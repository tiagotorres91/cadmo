# governance/ — the method applied to itself

The question this folder answers: *"does the framework have the artifacts the framework proposes?"*

Yes — and they're **real, not staged**. This project ran through its own method: a [value gate](value-gate.md) before it was built, [decision records](decisions/) for structural choices (the npm strategy; a protocol fix born from a real failure — with the alternatives that actually lost), and a [validation log](validation-log.md) recording who validated what against which version — including the adversarial review that found this repo's own gaps.

Use it as the non-fictional companion to [`examples/`](../examples/): the example shows the shape with a made-up feature; this folder shows the method deciding real things, with the alternatives that actually lost and the dates when it happened.
