# Context cache — answered questions, so nobody asks twice

The decision cache of the [context-question channel](../CONTRIBUTING.md#context-questions--the-elicitation-channel): when a `context-question` issue gets answered, the answer is **promoted here** (the closed issue stays as the audit trail; this file is the consultable index). Append-only — a changed answer gets a new row, never an edit.

**Relation to [`direction.md`](direction.md):** the big compass questions (goal, audience, scope, freeze) live THERE. This file is for the *incremental* Q&A that doesn't change direction — conventions, preferences, small rulings.

**Keep it thin.** Agents read this every session (rule zero); past ~150 lines of agent context, returns diminish. When a section grows stale or graduates into a real doc (as the first three questions graduated into `direction.md`), replace the rows with a pointer.
