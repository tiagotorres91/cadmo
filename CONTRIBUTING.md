# Contributing to Cadmo

Cadmo is a living method — improvements from real practice are exactly what it needs.

- **Found a gap, a sharper phrasing, or a real case?** Open an issue describing it.
- **Proposing a change?** One topic per issue; open a PR that closes it (`Closes #N`). Keep each PR focused.
- **New pattern or framework piece?** Explain the *real problem* it solves — Cadmo only adds what solves a problem someone actually has.

The method values right-sizing: prefer the smallest change that does the job. Docs are the product here —
write them so a newcomer understands the *why*, not just the *what*.
